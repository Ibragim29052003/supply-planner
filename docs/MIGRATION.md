Этот проект самостоятельно запускается в окне Avalonia и из командной строки.

В соседнем chat-bot-wb удалены учебный dev-маршрут, пункт навигации, Vite-плагин
и tools/supply-planner. Другие изменения сервиса не относятся к переносу.
Исходный Web/React-вариант, его инструкции, локальные данные и прежние Git hooks
сохранены в archives/chatbot-original-2026-11-04.zip; SHA-256 — manifest.json.
Кеши зависимостей и сборки не архивировались. Старые PDF и снимки описывают
веб-версию и не являются инструкцией для нового окна.

Для защиты используйте README.md и DEFENSE.md. Данные можно переносить через
JSON-сценарии; автоматического чтения рабочей базы/кабинетов ChatBot WB нет.
Неизвестные остатки не подменяются нулём. Проект не создаёт реальные поставки.

Это локальное отделение: удалённый репозиторий, push и сервер не настраивались.
Восстановление старого варианта возможно из архива; общие файлы сервиса следует
восстанавливать адресно, чтобы не затереть последующие изменения.
