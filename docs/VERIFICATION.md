# Проверка переноса · 04.11.2026

Среда: macOS, .NET SDK 10.0.400, целевая платформа net10.0.

## Автоматически проверено

- `./test.sh --no-restore`: 56 тестов успешно (50 ядро/файлы/CLI, 6 Desktop).
- Минимальность количества проверяется независимой дневной симуляцией для
  144 комбинаций остатков, спроса, сроков, упаковки и ожидаемого поступления.
- Сценарий examples/01-base.json: 692 единицы = Коледино 560 + Казань 132;
  неизвестный остаток сумки сохраняется неизвестным и не входит в итог.
- Изменение остатка футболки Коледино 100→150 даёт 250 вместо 300;
  Казань остаётся 132. Неверный черновик не заменяет рассчитанный план.
- Добавление поступления, событие DeliveryChanged и переключение стратегии.
- Запись/чтение проекта: сценарий, журнал, фильтры и выбранная строка;
  результат пересчитывается. Повреждённый файл не заменяет текущую работу.
- CLI действительно запущен из постоянной папки: JSON, Excel и состояние
  созданы в output/final-*. Повторный расчёт сохранённого состояния с фильтром
  Казани: две позиции, 132 единицы. В тестах проверены ошибки и защита перезаписи.
- Excel открывается библиотекой ClosedXML в тестах: типы ячеек, фильтры,
  закрепление заголовков, строки дневного баланса, суммы по складам и отсутствие
  внедрённых формул. Итоговый XLSX дополнительно проверен как ZIP/XML:
  три листа, корректное название самостоятельного проекта.
- Окно отрисовано headless Avalonia/Skia: обе темы, 1320×900 и 960×640;
  привязка поиска, выбор строки, команда расчёта, F1 и клавиатура графика.
  PNG в output/qa — снимки этой тестовой отрисовки, не нативного рабочего стола.
- Пакеты проверены через `dotnet list SupplyPlanner.slnx package --vulnerable
  --include-transitive`: известных уязвимых пакетов на момент проверки не найдено.
  Для исправленной D-Bus-зависимости явно закреплена версия 0.21.3.

## Обычный запуск

Из постоянной папки выполнено:

```bash
./run.sh --no-build --no-restore -- --open examples/01-base.json
```

Нативный процесс Avalonia на macOS запущен и продолжает работать, сообщений
об ошибках запуска нет. Отдельное управление мышью нативным окном в этой сессии
инструментами не выполнялось. Автотесты GUI используют headless-платформу.

## Перед защитой пройти вручную

1. Открыть JSON через системный диалог; отдельно проверить отмену диалога.
2. Изменить ячейку остатка двойным щелчком, рассчитать и проверить 250/132.
3. Сохранить проект через системный диалог и открыть его обратно.
4. Выгрузить Excel и открыть его в установленном табличном редакторе.
5. Переключить тему; проверить F1 / Fn+F1 и Cmd/Ctrl+S.
6. Закрыть и снова открыть окно: проверить восстановление последнего расчёта.

Нативные системные диалоги и отображение Excel в конкретной установленной
программе здесь не объявляются проверенными автоматически.
