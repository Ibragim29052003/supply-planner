# Проверка самостоятельного приложения · 04.11.2026

Среда: macOS arm64, .NET SDK 10.0.400, целевая платформа net10.0.

## Результат локальных проверок

`./test.sh -c Release` — **66 тестов успешно**: 57 ядро/файлы/CLI/Excel,
9 Desktop. Предыдущие промежуточные прогоны Debug также прошли. Ошибок
компиляции и предупреждений, подавленных ради сборки, нет.

- Количество проверяется независимой дневной симуляцией для 144 комбинаций
  остатков, спроса, доставки, упаковки и ожидаемого поступления.
- Вымышленные файлы examples/ проходят полный flow: импорт → CLI → JSON-состояние
  → повторный расчёт → Excel с фильтром Казани. Итоги: базовый 692/Казань132,
  доставка12дней 779/152, раннее поступление 749/152. Ошибочный дубликат отклонён.
- Изменение остатка Коледино100→150 даёт250 вместо300; Казань остаётся132.
  Отрицательные значения не заменяют прежний план. Пустая история сохраняется
  пустой и даёт «Нет оценки», а не выдуманный нулевой спрос.
- События DeliveryChanged/ShortageDetected/PlanCalculated, журнал, упаковка,
  стратегии прогноза, отсутствие оценки и дневные остатки покрыты тестами.
- Состояние восстанавливает исходные данные, журнал, фильтры и выбранную строку.
  Повреждённый файл не заменяет текущую работу. Перезапись входа с --force
  через ссылку и различие регистра защищена на соответствующих платформах.
- Команды действительно выполнены из постоянной папки: demo создаёт
  output/acceptance/import.json; calculate — plan.xlsx, plan.json и
  project.supply.json; повторная загрузка с фильтром Казани — kazan.xlsx.
  Эти файлы не включаются в Git или релиз.

## Окно

Headless Avalonia/Skia проверяет обе темы, размеры1320×900 и960×640, привязки
поиска, выбор строки, расчёт, справку F1, клавиатуру и мышь графика.
Подсказка рядом с курсором отсутствует; полный набор величин выбранного дня
находится под графиком. Нажатие также выбирает день.

Через реальные обработчики кнопок проверены «Сохранить», «Открыть» и «Excel»:
расчёт черновика при сохранении, повторная загрузка, экспорт выбранного склада,
отмена выбора и ошибка доступа. Сам выбор пути подменён IPlannerFileDialogs,
это не тест нативного диалога macOS. После загрузки другого сценария предлагаемая
дата поступления обновляется. PNG отрисовки — output/qa (не нативный рабочий стол).

## Excel

ClosedXML повторно открывает отчёты в тестах: типы чисел/дат, форматы,
фильтры, заголовки, закрепление, дневной баланс и суммы по складам.
OpenXML Validator не находит ошибок. Проверены длинные названия и артикулы,
пустые значения и защита от внедрения формул. Скрытые пояснения не увеличивают
высоту видимых строк. Цвета тела и отсутствие полос таблицы заданы явно.

Для визуальной проверки использован навык Spreadsheets: импорт и отрисовка
трёх листов через Artifact Tool. В его импортированном предпросмотре обнаружены
различия отображения объединённых ячеек и пользовательских форматов дат.
Исходный XLSX не менялся этим инструментом. Поэтому дополнительно выполнен
независимый импорт XLSX движком LibreOfficeDev26.8 и отрисовка листов:
названия, календарные даты и суммы в исходном файле корректны.
Подключённой управляемой сессии Microsoft Excel в этой беседе нет.
Дополнительно предпринята read-only проверка копии через AppleScript-словарь
установленного Excel: первый запрос завершился тайм-аутом, последующие не дали
объекта проверочной книги. Проверка именно движком Microsoft Excel поэтому
не объявляется успешной. Пользовательские книги и исходный XLSX не менялись.
XLSX является отчётом, импорт XLSX не реализован.

## Зависимости и публикация

`dotnet list SupplyPlanner.slnx package --vulnerable --include-transitive`:
для всех шести проектов известных уязвимых пакетов не найдено на момент проверки.
Пакеты закреплены, restore в CI выполняется с --locked-mode.
CI настроен для Release на Ubuntu, Windows и macOS.
[Запуск c9dd38c](https://github.com/Ibragim29052003/supply-planner/actions/runs/41875435648):
Windows и Ubuntu завершились успешно; macOS на момент выпуска ожидает runner.
Это очередь GitHub, результаты macOS CI не объявляются пройденными.
Локальный полный прогон macOS arm64 уже прошёл, см. начало отчёта.
Обновление только Markdown не запускает повторную сборку кода.

Скрипт scripts/publish-macos.sh создаёт self-contained single-file .app для
osx-arm64 и проверяет ad-hoc подпись codesign. Для полученного ZIP отдельно
проверен CRC. Учебные примеры,
инструкции и SHA-256 входят в поставку, локальные состояния и архивы — нет.
Архив распакован заново, подпись и SHA-256 проверены. `--help` и нативное окно
запущены с DOTNET_ROOT=/nonexistent и без SDK в PATH; ошибок запуска нет.
Состояние QA изолировано от пользовательского; завершён только наш QA-процесс.
Apple Developer ID/notarization не выполнялись; на другом Mac возможен
Gatekeeper. Распространение через ZIP не меняет сервер SellerStatus.

## Что остаётся пройти владельцу перед защитой

1. Выбрать/отменить файл в нативном диалоге; сохранить и открыть проект.
2. Открыть Excel в установленном редакторе и проверить читаемость при своём масштабе.
3. Проверить F1/Fn+F1 и Cmd/Ctrl+S на своей клавиатуре.
4. Закрыть/открыть окно и проверить пользовательское восстановление.

Автоматические проверки обработчиков и файлов не подменяют эти проверки ОС.
В отдельном репозитории оформлена реальная история переноса и последующих
исправлений без изменения авторов/дат старых коммитов. ChatBot WB в этой итерации
не изменялся; его накопленные несвязанные правки не коммитились и не отправлялись.
