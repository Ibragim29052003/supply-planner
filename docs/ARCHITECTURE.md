# Архитектура

- Core: чистая библиотека модели и расчёта. Стратегии через интерфейс, события
  синхронные .NET, точность decimal, запросы LINQ; нет UI/HTTP/файловых зависимостей.
- Infrastructure: внешние форматы и сценарии работы. Файлы пишутся через временный
  файл и rename в той же папке. Формат проекта версионирован, файл проверяется
  до замены состояния. Excel на ClosedXML. SQLite-адаптер сохранён для совместимости
  и как проверенная реализация хранения; оконный клиент его не использует.
- Desktop: XAML описывает layout, ViewModels содержат редактируемые строки,
  уведомления свойств и команды. View вызывает системные диалоги и клавиатуру;
  расчёт и форматы файлов не реализуются повторно в обработчиках UI.
  IPlannerFileDialogs отделяет нативный выбор пути от действий приложения;
  тесты проходят реальные обработчики с предсказуемыми путями/отменой/ошибкой.
  График обновляет подпись дня, без дублирующего popup.
- CLI: строгий разбор параметров, понятные ошибки и коды завершения. Отчёт,
  Excel и файл состояния построены на тех же Core/Infrastructure.

Установлен Avalonia11.3.9 с исправленным Tmds.DBus.Protocol0.21.3
(GHSA-xrw6-gwf8-vvr9). Проверка NuGet-уязвимостей не отключена.
Фиксированные версии и packages.lock.json обеспечивают воспроизводимость.

Ограничение файловых операций: каждый файл заменяется атомарно отдельно;
несколько выходных файлов CLI не образуют единую транзакцию файловой системы.
Excel формируется в фоне; основное состояние на момент экспорта фиксируется.


Распространение: self-contained single-file .app, учебная ad-hoc подпись.
Скрипт scripts/publish-macos.sh собирает во временной папке и заменяет только
готовый ZIP. Зависимости с RuntimeIdentifier используют отдельный lock в obj,
обычные packages.lock.json остаются переносимыми для locked-mode CI.
Приёмка на трёх ОС настроена в .github/workflows/ci.yml с закреплёнными SHA
официальных GitHub Actions. Архивы, кеши, результаты и пользовательские состояния
в Git не входят.

Упаковка следует структуре из [документации Avalonia](https://docs.avaloniaui.net/docs/deployment/macos).
Apple Developer ID/notarization и публикация на сервере для локальной защиты
не настраиваются. Для стороннего Mac сохранён исходный путь запуска с SDK10.
